# 团队职责登记

团队共 5 人。请在成员确定后填写 GitHub 用户名，避免仅记录昵称。

| 角色 | GitHub 用户名 | 仓库权限 | 主要职责 |
| --- | --- | --- | --- |
| 代码管理员 / 部署负责人 | 待填写 | Admin | 仓库规则、PR 合并、发布与回退 |
| 前端负责人 | 待填写 | Write | 前端任务拆分、质量和联调 |
| 前端开发成员 | 待填写 | Write | 页面、交互、测试与 PR |
| 后端负责人 | 待填写 | 对前端至少 Read | 接口协调与联调 |
| 机动/测试成员 | 待填写 | 按职责分配 | 测试、文档或跨端协作 |

## 评审要求

- 普通 PR：至少 1 名合格评审者批准。
- 代码管理员自己的 PR：由另一名具备 Write 权限的成员审核。
- 影响前后端契约的 PR：至少邀请另一端负责人参与评审。
