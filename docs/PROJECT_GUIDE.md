# 项目与架构说明

## 1. 项目目标

TikCookie 是一个团购业务方向的 Java 教学展示项目。团队共 5 人，采用前后端分离开发，目标是完成可联调、可部署、可重复演示的业务系统。

前端主要覆盖：

- 登录与身份状态展示
- 商品浏览、分类筛选与关键词搜索
- 店铺与商品详情
- 订单创建、查询和状态展示
- 个人中心与图片展示/上传

最终业务范围以团队任务和验收清单为准。

## 2. 前端职责

- 实现页面结构、交互和路由。
- 调用真实后端 API，不用静态假数据代替最终联调。
- 统一处理登录凭证、错误提示、加载状态和空状态。
- 对接口字段变化及时更新类型、页面和文档。
- 完成前端检查、测试和生产构建。
- 生成可由 Nginx 承载的前端制品或镜像。

## 3. 部署关系

- 浏览器通过 Nginx 访问前端页面。
- `/api` 请求由 Nginx 转发到 Spring Boot。
- 前端不直接连接 MySQL、Redis、RabbitMQ 或 Elasticsearch。
- 图片上传凭证和访问地址由后端控制，前端只使用约定接口。

## 4. 尚待项目骨架确定的内容

- Node.js 与包管理器版本
- Vue、Vite、Element Plus 的固定版本
- 状态管理、请求库、测试框架和目录结构
- 本地启动、检查、测试和构建命令
- 前端容器镜像和 CI/CD 工作流

这些决定需要通过 PR 落地并更新 README 与测试文档。
